# 读书阅读网站 — 设计文档

日期：2026-08-13
状态：已确认（待实现）

## 目标

一个极简的读书阅读网站，部署在 GitHub Pages 上，**任何人都能通过公开网址访问并阅读书籍**。用户自己提供 txt 书籍文件。首版只做最核心的功能：书架列表 + 分页阅读。

## 架构

纯静态网站，零后端、零框架、零构建。文件结构：

```
通用/
├── index.html          单页应用
├── style.css           样式
├── app.js              逻辑
├── books.json          书籍清单（由脚本自动生成，不手写）
├── books/              用户放置 txt 书籍的目录
│   ├── 三国演义.txt
│   └── ...
├── tools/scan-books.mjs   扫描 books/ 生成 books.json
├── deploy.bat             一键扫描+提交+推送
└── README.md              使用说明
```

- 部署：GitHub Pages，公开访问
- 书籍存储：直接作为仓库文件托管在 GitHub 上（这是"别人能看到书"的前提）

## 数据流

1. 页面加载 → `fetch('books.json')` 获取书籍清单 → 渲染书架
2. 用户点击某本书 → `fetch('books/<文件名>')` 获取全文 → 分页 → 显示第 1 页
3. 翻页 → 切换当前显示的分页内容
4. 字号变化 / 窗口尺寸变化 → 重新分页，尽量保持当前阅读位置

## 组件

### 书架视图
- 书籍卡片列表，每张卡片显示书名 + 首字/首字母作为封面占位
- 点击卡片进入阅读视图
- 书架为空时显示提示："暂无书籍，请把 txt 放进 books/ 文件夹"

### 阅读视图
- 顶栏：返回按钮 · 书名 · 页码（`当前页 / 总页数`）
- 正文区：按可视高度分页显示
- 底栏：上一页 / 下一页按钮 · 字号 `A-` `A+` · 深浅色切换
- 键盘：`←` `→` 翻页，`Esc` 返回书架

## 关键技术点

### 1. 中文编码（乱码处理）
中文 txt 常见 GBK/GB2312 编码，直接按 UTF-8 读取会乱码。处理方式：
- 用 `fetch` 读取文件为 `ArrayBuffer`
- 先尝试 `TextDecoder('utf-8', { fatal: true })` 解码
- 失败则回退 `TextDecoder('gb18030')`（GBK 超集，覆盖 GBK/GB2312）

这样 UTF-8 与 GBK 编码的 txt 都能正确显示，用户无需关心编码。

### 2. 分页算法
不按字数分页，而是按可视区域实际能容纳的行数分页：
- 逐字符/逐行测量，累计到超出容器高度即切为一页
- 字号、窗口尺寸变化时触发重新分页
- 保证每页内容完整、不截断半行

### 3. 书籍清单
`books.json` 由脚本 `tools/scan-books.mjs` 扫描 `books/` 目录自动生成，格式：

```json
[
  { "title": "三国演义", "file": "books/三国演义.txt" }
]
```

- `title` = 文件名去掉 `.txt` 后缀
- 用户不手写清单，避免遗漏

## 错误处理

- `books.json` 加载失败 → 书架区显示错误提示
- 某本书 txt 加载失败 → 显示"书籍加载失败"，可返回书架
- 书架为空 → 显示"暂无书籍"提示

## 加书流程（用户日常操作）

1. 把新 txt 拖进 `books/` 文件夹
2. 双击 `deploy.bat`（自动：扫描生成清单 → git add → commit → push）

完成后公开网址立即可见新书。

## 范围（首版不做，后续可加）

- 阅读进度记忆、书签、搜索、章节目录、封面图
- 网页端上传（改为直接放文件进仓库，才能让别人看到）
- 登录、评论等

## 部署

1. 初始化 git 仓库（已完成）
2. 创建 GitHub 远程仓库并推送
3. 开启 GitHub Pages
4. 得到公开网址 `https://<用户名>.github.io/<仓库名>/`

## 默认约定

- 书名默认取文件名（去 `.txt` 后缀）
- 阅读视图默认浅色主题，可一键切深色
